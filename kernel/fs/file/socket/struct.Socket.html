Expand description

Socket structure representation. Socket alone can’t do much. These need to be created by pair, Each socket will be tide to both endpoint but we’ll access only one by writing or reading. UNIX domain will create 2 buffers for both endpoint of the socket. INET domain is not implemented but could create an endpoint of the socket bound to the network interface TODO? Maybe embed the woffset inside the buffer to precisely know how much byte as been written
